# Pannkakor – Enkelt recept på pannkakor

En enkel webbsida med ett klassiskt recept på pannkakor, byggd med HTML och CSS.

## Innehåll

- **index.html** – Huvudsidan med receptet och bilder.
- **page.css** – Anpassad stil för sidan.
- **img/** – Bilder för receptet och serveringsförslag.

## Förhandsgranska

Öppna `index.html` i din webbläsare för att se sidan.

## Struktur

```
├── .gitignore
├── favicon.ico
├── index.html
├── page.css
├── README.md
└── img/
    ├── details1.png
    ├── details2.png

```
